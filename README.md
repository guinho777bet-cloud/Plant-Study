# Study Tracker

Um projeto simples para registrar e acompanhar o tempo de estudo.

## Funcionalidades

- Adicionar o nome do estudo
- Iniciar o cronômetro
- Contar o tempo de estudo

## Tecnologias

- HTML
- CSS
- JavaScript

## Como funciona

Digite o nome da matéria ou assunto que deseja estudar e clique em **Iniciar estudo**.

O cronômetro começa a contar o tempo.

Ao finalizar, clique em **Parar estudo**.
